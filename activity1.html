Course Summary

Statistics 1 — what we've covered so far

A running summary of the concepts worked through this course, from raw data types to how we describe and visualize them.

1 · Types of Data

Categorical (Qualitative) Data

Describes qualities, labels, or groups rather than quantities — things you can sort into categories but not meaningfully do arithmetic on.

  • Nominal — categories with no natural order (blood group, gender, city)
  • Ordinal — categories with a meaningful order (satisfaction rating, class grade)

Numerical (Quantitative) Data

Represents measurable quantities where arithmetic (differences, averages) is meaningful.

  • Discrete — countable, whole-number values (number of siblings, cars sold)
  • Continuous — can take any value in a range (height, temperature, time)

3 · Visualizing Data

Bar Chart

Compares a numerical value across discrete categories using bars of varying height/length.

Pie Chart

Shows each category's share of a whole as a slice of a circle — best for a handful of categories.

Scatter Plot

Plots pairs of numerical values as points, useful for spotting relationships or correlation between two variables.

Stacked Bar Chart

A bar chart where each bar is split into sub-segments, showing both a category total and its composition.

4 · Measures of Central Tendency

Mean

The arithmetic average — sum of all values divided by the count. Sensitive to outliers.

x̄= Σ xin
sum of all values ÷ number of values

Median

The middle value when data is sorted — splits the dataset in half. Robust to outliers.

M=value at position n + 12
middle of the sorted data (average of two middles if n is even)

Mode

The most frequently occurring value — the only measure of central tendency that works for categorical data.

mode = value(s) with highest frequency

Range

The simplest measure of spread — the gap between the largest and smallest values.

range = xmax − xmin
5 · Variance & Standard Deviation

Variance

Measures how far, on average, each value is from the mean — found by squaring every deviation (so negatives don't cancel out) and averaging the result.

σ2= Σ (xi − x̄)2n
population variance · use n − 1 in the denominator for a sample

Standard Deviation

The square root of variance — brings the spread back into the original units, which makes it much easier to interpret than variance.

σ= √ Σ (xi − x̄)2n
σ = √variance
